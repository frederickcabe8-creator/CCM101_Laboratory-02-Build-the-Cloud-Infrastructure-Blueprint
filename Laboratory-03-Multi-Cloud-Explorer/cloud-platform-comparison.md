### Discussion Questions

**1. Which cloud provider offers the broadest range of services?**
AWS offers the broadest range of services, with over 200 offerings covering nearly every compute, storage, networking, analytics, and AI use case. Its head start since 2006 gave it more time to build out a mature, extensive catalog than either competitor.

**2. Which provider best integrates with Microsoft technologies?**
Microsoft Azure best integrates with Microsoft technologies, since it was built by the same company as Windows Server, Active Directory, and Microsoft 365. Organizations already using these tools get near-seamless identity management and hybrid deployment options through Azure Arc.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**
Google Cloud Platform is generally considered strongest in AI and Kubernetes. GCP created Kubernetes itself and offers GKE as the industry benchmark, plus advanced AI/ML tools like Vertex AI and custom TPUs for high-performance training.

## Checkpoint 6 — Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | Pay-as-you-go pricing, huge free-tier/startup credit programs, and the largest ecosystem to scale into as the business grows. |
| Enterprise Organization | AWS or Azure | Both offer enterprise-grade SLAs, compliance certifications, and extensive support tiers; choice depends on existing vendor relationships. |
| Microsoft Environment | Azure | Native integration with Windows Server, Active Directory, and Microsoft 365 reduces migration friction and licensing costs. |
| AI / Machine Learning | GCP | Vertex AI, TPUs, and Google's research-driven AI tooling (origin of TensorFlow) give it an edge for ML workloads. |
| Kubernetes Deployment | GCP | GKE is the most mature managed Kubernetes offering, built by the same team that created Kubernetes. |
| Global Web Application | AWS | Largest number of regions/edge locations combined with mature auto-scaling and CDN (CloudFront) for global low-latency delivery. |
