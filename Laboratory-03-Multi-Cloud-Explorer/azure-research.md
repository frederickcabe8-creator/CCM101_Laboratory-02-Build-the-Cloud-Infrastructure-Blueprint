# Microsoft Azure — Research Notes

## Brief Overview
Microsoft Azure is Microsoft's cloud computing platform, launched in 2010. It is known for its deep integration with Microsoft's enterprise software ecosystem (Windows Server, Active Directory, Microsoft 365) and is a top choice for organizations already invested in Microsoft technologies.

## Global Infrastructure
Azure infrastructure is built around **Regions** (60+ worldwide, the most of any provider) grouped into **Geographies**, with **Availability Zones** for fault tolerance within a region. Azure also has an extensive network of edge/CDN locations.

## Cloud Management Console
The **Azure Portal** is the primary web-based management interface. Azure also provides Azure CLI, Azure PowerShell, Azure Cloud Shell, and Azure Resource Manager (ARM) templates for infrastructure-as-code deployment.

## Four (4) Core Services
1. **Azure Virtual Machines** – on-demand, scalable virtual servers.
2. **Azure Blob Storage** – object storage for unstructured data.
3. **Azure Active Directory (Microsoft Entra ID)** – identity and access management, tightly integrated with Microsoft 365.
4. **Azure SQL Database** – fully managed relational database service.

## Three (3) Advantages
1. Seamless integration with existing Microsoft products (Windows Server, Active Directory, Office/Microsoft 365).
2. Strong hybrid cloud support through Azure Arc and Azure Stack for organizations that can't fully move off-premises.
3. Widest regional presence, useful for compliance and data residency requirements.

## Typical Enterprise Use Cases
- Organizations migrating existing Windows Server/Active Directory environments to the cloud.
- Hybrid cloud deployments that keep some infrastructure on-premises.
- Enterprises standardized on Microsoft 365 wanting unified identity and security management.
