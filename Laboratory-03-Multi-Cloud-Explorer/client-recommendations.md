# Google Cloud Platform (GCP) — Research Notes

## Brief Overview
Google Cloud Platform (GCP) is Google's cloud computing offering, publicly launched in 2008 (starting with App Engine). GCP leverages the same infrastructure Google uses for its own products (Search, YouTube, Gmail) and is especially known for strength in data analytics, AI/ML, and Kubernetes/container orchestration.

## Global Infrastructure
GCP infrastructure is organized into **Regions** (40+ worldwide) and **Zones** (isolated locations within a region). It also benefits from Google's private global fiber network, which connects its data centers for high-speed data transfer.

## Cloud Management Console
The **Google Cloud Console** is the web-based interface for managing GCP resources. It also provides the `gcloud` CLI, Cloud Shell (browser-based terminal), and Terraform/Deployment Manager for infrastructure-as-code.

## Four (4) Core Services
1. **Compute Engine** – customizable virtual machines.
2. **Cloud Storage** – object storage for unstructured data.
3. **Google Kubernetes Engine (GKE)** – managed Kubernetes for container orchestration (considered the industry benchmark).
4. **Cloud IAM** – identity and access management for GCP resources.

## Three (3) Advantages
1. Industry-leading Kubernetes/container support (GKE), since Google created Kubernetes.
2. Strong AI/ML tooling (Vertex AI, TensorFlow origin, TPUs) for high-performance machine learning workloads.
3. Competitive pricing model with sustained-use discounts and strong data analytics tools (BigQuery).

## Typical Enterprise Use Cases
- AI/ML and data-science-heavy workloads needing high-performance computing (TPUs, Vertex AI).
- Container-native applications built around Kubernetes/microservices.
- Big data analytics and real-time analytics pipelines (BigQuery, Dataflow).
